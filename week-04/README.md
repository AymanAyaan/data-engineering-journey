# Module 4 Assignment: Dictionary, CSV, and JSON

## ১. কোন লেভেল পর্যন্ত করেছেন
লেভেল ৩ পর্যন্ত সম্পূর্ণ করেছি (dictionary দিয়ে পণ্যের হিসাব, CSV লেখা ও পড়া, এবং JSON রিপোর্ট তৈরি)।

## ২. কোথায় আটকেছিলেন, আর কীভাবে বের হলেন
প্রথমে কোর্স repo-টি ZIP হিসেবে নামানো থাকায় `git pull` কাজ করছিল না এবং CSV থেকে পড়ার সময় `amount` স্ট্রিং হিসেবে আসছিল। পরে `git clone` করে নতুন ফাইলগুলো এনেছি এবং CSV-এর মান যোগ করার আগে `float()` দিয়ে রূপান্তর করে সমাধান করেছি।

## ৩. CSV আর JSON-এর পার্থক্য
CSV সব ডেটাকে সাধারণ টেক্সট (string) হিসেবে সংরক্ষণ করে, তাই সংখ্যা নিয়ে হিসাব করার আগে `float()` বা `int()` দিয়ে বদলে নিতে হয়। অন্যদিকে JSON ডেটার নিজস্ব ধরন (যেমন float, int, dictionary) সংরক্ষণ করে, তাই `json.load()` করলে সংখ্যাগুলো সরাসরি `float` হিসেবেই ফেরত আসে।
